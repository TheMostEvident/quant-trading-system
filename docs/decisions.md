## 계약 변경 규칙

- `0.1.0`은 첫 문서 계약이다. 구현 완료나 검증된 금융 모형의 버전이 아니다.
- 기존 필드 의미·단위·필수성이 바뀌면 계약 버전과 변환/거부 방침을 함께 기록한다.
- 공급자 필드명은 어댑터 경계에서 정규화하고 원천을 보존한다.
- 새로운 상품이 기존 `InstrumentSpec`의 손익·수량 의미를 충족하지 못하면 계약을 확장하고 fixture를 추가한다.
- Layer 2의 채택 모형이나 정책 최적화 방법이 바뀌어도 공통 계약의 의미가 유지되면 Layer 1·3의 핵심 로직을 변경하지 않는다.
